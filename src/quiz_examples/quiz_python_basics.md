### 1. Which keyword is used to define a function in Python?
- [ ] function
- [x] def
- [ ] func
- [ ] lambda
> Explanation: The `def` keyword is used to define a function in Python.

### 2. What data type is the result of `3 / 2` in Python 3?
- [ ] int
- [x] float
- [ ] str
- [ ] complex
> Explanation: In Python 3, the `/` operator always performs true division and returns a float, even if the result is a whole number.

### 3. Which of the following is a mutable data type in Python?
- [ ] tuple
- [x] list
- [ ] str
- [ ] int
> Explanation: Lists are mutable, meaning their contents can be changed after creation, unlike tuples and strings which are immutable.

### 4. What does the `len()` function do?
- [ ] Converts a value to a string
- [x] Returns the number of items in an object
- [ ] Rounds a number
- [ ] Sorts a list
> Explanation: `len()` returns the number of items in a sequence or collection, such as a list, string, or dictionary.

### 5. How do you start a single-line comment in Python?
- [ ] //
- [ ] /* */
- [x] #
- [ ] --
> Explanation: Python uses the `#` symbol to denote a single-line comment.

### 6. Which loop is guaranteed to execute at least once in Python?
- [ ] for loop
- [ ] while loop
- [x] None — Python has no built-in loop that guarantees at least one execution
- [ ] do-while loop
> Explanation: Unlike some other languages, Python does not have a native `do-while` loop, so no loop structure guarantees at least one execution by default.

### 7. What is the correct way to create a dictionary in Python?
- [ ] `dict = [1, 2, 3]`
- [x] `dict = {"key": "value"}`
- [ ] `dict = (1, 2)`
- [ ] `dict = <1, 2>`
> Explanation: Dictionaries in Python are created using curly braces with key-value pairs separated by colons.

### 8. What does the `append()` method do to a list?
- [ ] Removes the last element
- [x] Adds an element to the end of the list
- [ ] Sorts the list in place
- [ ] Reverses the list
> Explanation: The `append()` method adds a single element to the end of an existing list.

### 9. Which of these correctly imports the `math` module?
- [ ] `include math`
- [x] `import math`
- [ ] `using math`
- [ ] `require math`
> Explanation: Python uses the `import` statement to bring in external modules like `math`.

### 10. What will `type(5 == 5)` return?
- [ ] `<class 'int'>`
- [x] `<class 'bool'>`
